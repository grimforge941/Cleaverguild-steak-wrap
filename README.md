Cleaverguild Steak Wrap Recipe
A simple HTML webpage built while learning web development. This project includes headings, paragraphs, links, images, lists, and semantic HTML structure.
Features
- Organized recipe layout
- Ingredients list using <ul>
- Instructions list using <ol>
- Images with alt text
- Semantic elements like <main>, <section>, and <figure>
- Accessible and clean HTML structure
What I Learned
- How to structure a webpage
- How to use headings correctly
- How to nest lists and elements
- How to add images and captions
- How to write semantic, readable HTML
